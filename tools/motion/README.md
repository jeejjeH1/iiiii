# موتور ساخت ویدیوی معرفی گل‌لایو

از عکس‌های واقعی صفحه‌های برنامه، ویدیوی عمودی ۱۰۸۰×۱۹۲۰ (مناسب استوری) با صدا می‌سازد: گوشی که برنامه را نشان می‌دهد،
نشانگری که روی گزینه‌ها می‌زند، بزرگ‌نمایی بخش مهم صفحه، عنوان و توضیح، و پایان با لوگو و «دانلود از کافه‌بازار».
موسیقی و افکت‌های صوتی همین‌جا ساخته می‌شوند (بدون مشکل حق پخش).

## ساختن

نیاز: Node.js با Playwright و Chromium، Python 3 با numpy و scipy، و ffmpeg.

```sh
./make.sh            # همه‌ی ویدیوها
./make.sh 1-rating   # فقط یکی
```

خروجی در `out/<نام>-final.mp4`. بار اول `fetch.sh` فونت‌ها، لوگو و عکس‌های صفحه را می‌آورد
(عکس‌ها از ریلیز `android-screens` که کار `screens` در گردش‌کار اندروید می‌سازد).

## فایل‌ها

- `engine.html` — صحنه: پس‌زمینه، گوشی، نشانگر، بزرگ‌نمایی، متن‌ها و پایان. همه چیز تابعی از زمان است (`render(t)`).
- `videos/*.js` — هر ویدیو: عنوان، توضیح‌ها و زمانشان، صفحه‌ها، جای لمس‌ها و بخش‌هایی که بزرگ می‌شوند.
- `render.js` — فریم به فریم با Chromium عکس می‌گیرد و با ffmpeg ویدیو می‌سازد. `--preview 2,5,8` فقط چند فریم در `prev/`.
- `audio.py` — موسیقی ۱۱۲ ضرب در دقیقه و افکت‌ها (لمس، تغییر صفحه، بزرگ‌نمایی، اعلان، پایان) روی همان لحظه‌ها.
- `grid.py` — عکس صفحه با خط‌کش پیکسلی، برای پیدا کردن مختصات بزرگ‌نمایی و لمس.

مختصات در `videos/*.js` بر حسب پیکسل عکس صفحه (۸۰۰×۱۷۲۰) است.
